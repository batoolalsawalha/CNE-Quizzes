## 🏛️ نظرة عامة ومبدأ العمل الأكاديمي

تم بناء المنصة استجابة لاحتياجات طلاب قسم هندسة شبكات الحاسوب ولجنة التخصص:
* **فصل كامل بين الكود والبيانات:** جميع المواد (45 مادة)، الامتحانات (84 كويز)، والأسئلة (69 سؤالاً معتمداً) مخزنة في قاعدة بيانات JSON ذات كتابة فورية (`data/database.json`).
* **عدم الحاجة لتعديل الكود مستقبلاً:** يستطيع أي عضو في اللجنة إضافة مواد أو كويزات جديدة، أو تعديل الأسئلة، أو استيراد ملفات CSV و JSON مباشرة عبر لوحة التحكم الرسومية المحمية.
* **ملفات المصدر الأصلية (`qu/`) للقراءة فقط:** تبقى ملفات الأسئلة الأصلية كما هي تماماً دون أي تعديل أو حذف.

## 🔐 بيانات تسجيل دخول المشرف (Admin Credentials)

لحماية النظام ومنع الطلاب من الوصول للوحة التحكم أو تعديل الأسئلة:
* **رابط دخول المشرفين:** يتم الوصول إليه من خلال النقر على رابط **"بوابة المشرفين 🔒"** في أسفل الصفحة (Footer) أو عبر التوجه مباشرة إلى الرابط:  
  `http://localhost:3000/#admin`
* **اسم المستخدم الافتراضي:** `cne_admin`
* **كلمة المرور الافتراضية:** `cne_committee_2025`
* **مستوى الأمان والتشفير:** كلمات المرور لا تُخزن كنصوص عادية إطلاقاً، بل تُشفر عبر خوارزمية التشفير القياسية **PBKDF2** مع Salt عشوائي مكون من 16 بايت وتشفير SHA-512 عبر 100,000 دورة.
* **تغيير كلمة المرور:** يمكن للمسؤول تغيير اسم المستخدم وكلمة المرور في أي وقت من زر `🔐 حساب المشرف` داخل لوحة التحكم.

## 🚀 كيفية تشغيل المشروع (Quick Start)

### التشغيل على نظام Windows (نقرة زر واحدة دون أي تثبيت إضافي)
يحتوي المشروع على بيئة Node.js مدمجة ومستقلة داخل المجلد `.bin/`. لتشغيل المنصة:
1. انقر نقراً مزدوجاً على الملف:
   ```cmd
   start.bat
   ```
2. أو من موجه الأوامر (CMD / PowerShell):
   ```powershell
   .\.bin\node.exe server/server.js
   ```
3. افتح المتصفح وتوجه إلى:
   ```
   http://localhost:3000
   ```

### التشغيل على أي نظام آخر (Linux / macOS / Cloud)
```bash
# تشغيل خادم Node.js (بدون أي dependencies خارجية!)
node server/server.js
```

### تشغيل فحص واختبار النظام (Test Suite)
للتأكد من سلامة جميع محركات النظام، والمصادقة الأمنية، وخصوصية الطلاب:
```bash
.\.bin\node.exe test_api.js
```

## 🌟 الميزات والخصائص المطبقة

### 1. دعم كامل لمواد التخصص (45 مادة)
* تم مسح مجلد `qu/` بالكامل وربط جميع المواد المتاحة (كالكولاس، دوائر كهربائية، شبكات، أنظمة تشغيل، برمجة، إحصاء، معالجات دقيقة، منطق رقمي، اتصالات، وغيرها).
* تم توليد **84 كويزاً** لمختلف السنوات وامتحانات الميد والفاينل.
* بنية مرنة تقبل إضافة أي مادة جديدة في ثوانٍ.

### 2. دعم كامل للأسئلة المصورة (Questions with Diagrams)
* يدعم النظام الأسئلة النصية، والأسئلة المصورة (مخططات دوائر، جداول منطقية، معادلات ورقية).
* عرض الصور بدقة عالية ومتجاوبة مع الهواتف والحواسيب.
* **نافذة تكبير الصور (Lightbox Modal):** يمكن للطالب أو المشرف النقر على أي رسمة لتكبيرها وفحص تفاصيلها بدقة ثم إغلاقها بسلاسة.
* تظهر الصور بوضوح داخل ورقة الاختبار، وتقرير المراجعة، ونماذج الطباعة PDF.

### 3. تجربة اختبارات نموذجية للطلاب
* حرية كاملة في التنقل بين الأسئلة (`السابق` و `التالي` أو النقر المباشر على خريطة الأسئلة).
* إمكانية تغيير الإجابة في أي وقت قبل التسليم النهائي.
* حفظ تلقائي مؤقت للإجابات في المتصفح للحماية في حال انقطاع الاتصال.
* **عرض النتيجة من 100:** تظهر النتيجة بصيغة واضحة للطلاب (مثال: `85 / 100`) مصحوبة بالنسبة المئوية وتصنيف الأداء.
* مراجعة كاملة مع مقارنة إجابة الطالب بالإجابة النموذجية وشرح خطوات الحل.

## 🔒 حماية خصوصية المصادر (Privacy Protection)

وفقاً للتوجيهات الصارمة الخاصة بخصوصية الامتحانات:
* **الطلاب:** لا يظهر لهم إطلاقاً اسم ملف الامتحان الورقي الأصلي أو رقم الصفحة في أي مكان (تم تجريد هذه البيانات برمجياً من الـ Backend والـ Frontend).
* **المشرفون فقط:** تظهر بيانات ملف المصدر ورقم الصفحة داخل لوحة التحكم وفي قائمة المراجعة لتمكين أعضاء اللجنة من تدقيق السؤال بالرجوع للورقة الأصلية.

## 🖨️ الطباعة ونماذج PDF الرسمية

يوفر ملف `public/quiz-print.html` محرك طباعة احترافي مخصص لورق A4 متوافق مع ميزة "حفظ كـ PDF" في كافة المتصفحات:
1. **ورقة امتحان الطالب (Student Exam Paper):**
   * تحتوي على ترويسة رسمية، حقول كتابة اسم الطالب ورقمه وشعبته، نصوص الأسئلة، المخططات والصور الهندسية، ودوائر الاختيارات `( A ) ( B ) ( C ) ( D )` بدون أي حلول.
2. **نموذج الإجابة الرسمي (Answer Key PDF):**
   * مخصص للمشرفين المعتمدين فقط (يتطلب مصادقة الأدمين).
   * يوضح الإجابات الصحيحة بعلامة `[✓]` مع إبراز الشروحات وخطوات الحل الرياضية.

## 📱 تطبيق الويب التقدمي (PWA Support)

* التطبيق يدعم العمل كـ **Progressive Web App** قابل للتثبيت على الهواتف (Android / iPhone) والحواسيب عبر المتصفح مباشرة.
* يحتوي على `manifest.json` و `sw.js` (Service Worker) لتخزين ملفات التصميم والأيقونات محلياً لسرعة فائقة.
* يظهر زر "تثبيت" في أعلى الصفحة عند فتح الموقع في متصفح يدعم الـ PWA.

## 🐳 النشر والحفظ عبر Docker

لتشغيل المنصة في بيئة سحابية أو خادم إنتاج دائم مع حفظ مستمر للبيانات:
```bash
# تشغيل التطبيق بالخلفية
docker-compose up -d --build
```
يضمن ملف `docker-compose.yml` حفظ مجلد `data/` ومجلد الصور في Volume مستقل على القرص بحيث لا تُفقد البيانات عند إعادة تشغيل الحاوية.
